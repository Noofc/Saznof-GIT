# Scripts

Utilitarios de manutencao, diagnostico e geracao de imagens ficam aqui para manter a raiz do bot limpa.

Use os scripts a partir da raiz do projeto ou diretamente desta pasta. O arquivo `_path.py` ajusta o `sys.path` para permitir imports de `functions`, `modules`, `commands` e demais pacotes do bot.

Arquivos gerados devem ir para:

- `assets/receipts/` para comprovantes de teste.
- `assets/generated/` para imagens e demonstracoes geradas.
